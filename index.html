🏷️ What is BIMI?

BIMI (Brand Indicators for Message Identification) allows brands to display their logo in supported email clients' avatar slots. This increases trust and recognition.

🎨 BIMI SVG Requirements

  • ✓ SVG Tiny 1.2 profile required
  • ✓ Square aspect ratio (1:1)
  • ✓ No raster images (PNG/JPG embedded)
  • ✓ No scripts or animations
  • ✓ Max 32KB file size
  • ✓ HTTPS only hosting

🔐 VMC (Verified Mark Certificate)

VMCs are special certificates that prove you own the trademark for your logo. When present, email clients show a verified checkmark badge.
